# 🌲 НОЧНОЙ ЛЕС — бесконечный хоррор-раннер (v2.0 «Руби и беги»)

3D-игра в браузере на Three.js: ты один в бесконечном ночном лесу, за тобой охотятся твари.
Беги, руби деревья топором или бензопилой, жги костры, гони машину с дрифтом
и сшибай монстров бампером. Но не останавливайся.

## Как запустить

Открой игру: **https://nikitabuhmiller91-bit.github.io/night-forest/**
Или локально: просто открой `index.html` в браузере (нужен интернет — Three.js грузится с CDN).

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Shift | бег (тратит выносливость) |
| Мышь | обзор |
| ЛКМ | рубить дерево / пилить / бить тварь |
| F | фонарик (твари боятся света) |
| E | сесть/слезть с транспорта, починить ломаный велик ключом 🔧 |
| G | залить канистру в машину (в машине) / заправить бензопилу (пешком) |
| 1 / 2 / 3 | руки / топор 🪓 / бензопила ⛓ |
| B | костёр из 3 дров 🔥 (твари его боятся) |
| H | гудок машины (отгоняет тварей) |
| Space | ручник в машине — ДРИФТ |

## Что нового в v2.0

- 🏚 **Домики с комнатами** — теперь в них можно заходить через дверь, внутри лут (топоры, бензопилы, аптечки). Но твари умеют **ломать стены**!
- 🔨 **Поломанные стены** — застрявшая тварь пробивает стену дома и лезет внутрь
- 🪓 **Рубка деревьев** — у каждого дерева прочность; топор рубит в 3 удара, бензопила пилит быстро, но жрёт бензин. Дерево падает, разбрасывая брёвна 🪵
- 🔥 **Костёр** — крафт из 3 дров, отпугивает тварей в радиусе 9 м, догорает за 2 минуты
- 🚗 **Физика машины** — продольное/боковое скольжение шин, дрифт на ручнике, из салона видно торпедо и крутящийся руль
- 💥 **Урон кузову** — столкновения мнут машину (падает максимальная скорость, тряска экрана), 0% кузова — машина глухая
- 👾 **4 вида монстров** с разным поведением:
  - **Тень** — обычный преследователь
  - **Ползун** — юркий, ходит зигзагами, очень быстрый
  - **Громила** — танк с оранжевыми глазами, почти не боится света, 120 HP
  - **Хозяин леса** 💀 — босс каждые 5 минут, 420 HP, полоса здоровья на экране
- 📊 **Рекорды**: время, дистанция и убитые твари сохраняются в браузере

## Ещё в игре

- 🌲 Бесконечный процедурный лес (чанки, сид-генерация)
- 🚲 Велосипеды ломаются ровно после **3 минут** езды, чинятся гаечным ключом 🔧
- 🚗 Машины: расход **1 л бензина за 30 секунд**, в каждой случайный бак 0.3–7.5 л
- 🔋 Лут: батарейки (+45% фонарика), канистры, аптечки (+35 HP), ключи
- 🚪 Подбор предметов работает и внутри домов (радиус подбора 1.7 м)
- ⚡ Свет фонарика замедляет тварей (по-разному для каждого вида); тварей на скорости > 36 км/ч можно сшибать машиной
- 🎵 Все звуки — процедурный WebAudio: ветер, мотор, бензопила, шаги, сердце, гудок
- 🗺 Радар: машины, велосипеды, монстры, костры и предметы
