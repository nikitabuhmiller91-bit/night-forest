🌍 Мировая биржа валют

Статический сайт на чистом HTML/CSS/JS: курсы всех валют мира из официальных источников, карта мира и официальные курсы центральных банков.

Только информация — без переводов, покупки и продажи. Данные подтягиваются из бесплатных публичных API прямо в браузере (сервер не нужен).

## Возможности

- 📊 Таблица ~160 мировых валют: сколько стоит валюта, поиск и сортировка, выбор базовой валюты (USD, EUR, RUB, GBP, JPY и др.)
- 💱 Конвертер: любая сумма, любые две валюты из списка
- 🗺 Интерактивная карта мира (Leaflet): цвет страны = сколько местной валюты дают за 1 USD (лог-шкала); наведение показывает точный курс
- 🏦 Банки мира: официальные курсы центробанков — ЦБ РФ (с изменением к предыдущему дню), ЕЦБ, НБП (Польша), ЧНБ (Чехия)

## Структура (папка world-currency-exchange в репозитории night-forest)

    world-currency-exchange/
    ├── index.html        страница
    ├── css/style.css     оформление
    └── js/
        ├── data.js       реестр валют (названия, ISO-коды)
        ├── app.js        курсы, таблица, конвертер, карта
        └── banks.js      курсы центральных банков

## Источники данных (официальные / публичные API)

| Источник | Что даёт | API |
|---|---|---|
| open.er-api.com | Курсы 160+ валют, обновление раз в сутки | https://open.er-api.com/v6/latest/USD |
| Европейский центральный банк | Официальный курс евро (резервный источник) | https://api.frankfurter.dev/v1/latest?base=EUR |
| Центральный банк РФ | Официальные курсы к рублю + сравнение с предыдущим днём | https://www.cbr-xml-daily.ru/daily_json.js |
| Национальный банк Польши | Средние курсы (Tabela A) | https://api.nbp.pl/api/exchangerates/tables/A?format=json |
| Чешский национальный банк | Официальные курсы к кроне | https://api.cnb.cz/cnbapi/exchangerates/daily-en.txt |

## Как запустить

Просто открой index.html в браузере (нужен интернет — данные идут запросами к API).

### GitHub Pages

Settings → Pages → Deploy from branch → в Source выбери папку /world-currency-exchange.
Сайт откроется по адресу вида https://nikitabuhmiller91-bit.github.io/night-forest/world-currency-exchange/

## Дисклеймер

Курсы носят справочный характер и могут запаздывать. Коммерческие банки публикуют собственные курсы покупки/продажи с маржой — для точных сумм сверяйся с банком.
