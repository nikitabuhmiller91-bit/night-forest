# 🌲 НОЧНОЙ ЛЕС — бесконечный хоррор-раннер

3D-игра в браузере на Three.js: ты один в бесконечном ночном лесу, за тобой гонятся
монстры. Беги. Найди велик или машину. Не останавливайся.

## Как запустить

Просто открой `index.html` в браузере (нужен интернет — Three.js грузится с CDN).
Либо: `python3 -m http.server` в этой папке → http://localhost:8000

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Shift | бег (тратит выносливость) |
| Мышь | обзор |
| F | фонарик (тратит заряд, но монстры боятся света) |
| E | сесть / выйти из транспорта, починить велик ключом |
| G | залить канистру бензина в машину |

## Что в игре

- 🏃 **Бесконечный процедурный лес** — мир генерируется чанками на ходу
- 👹 **Монстры** — их становится больше и они быстрее со временем; свет замедляет их, машиной на скорости можно сбивать
- 🚲 **Велосипеды** — изнашиваются и ломаются ровно после **3 минут** езды, чинятся гаечным ключом 🔧
- 🚗 **Машины** — расход **1 л бензина за 30 секунд**, в каждой случайное количество топлива (0.3–7.5 л)
- 🏠 **Постройки** — заброшенные дома с редкими светящимися окнами
- 📘🔋🧰💊 Лут: батареи, канистры, аптечки, гаечные ключи
- 📟 HUD: здоровье, выносливость, заряд фонарика, спидометр, датчик топлива/износа, радар
- 🔊 Звук: ветер, сердцебиение при приближении монстров, шаги, гул мотора (WebAudio, без файлов)
- 🏆 Рекорд времени выживания сохраняется в localStorage
